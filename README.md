# Análise dos Preços de Combustíveis no Brasil em 2025

## Sobre o projeto

Este projeto foi desenvolvido como parte do **Trabalho de Extensão III**, da disciplina/atividade de Análise de Dados com Python.

O objetivo foi coletar, tratar, analisar e extrair inferências estatísticas de uma base de dados pública, investigando o comportamento dos preços de revenda da gasolina e do etanol no Brasil durante o ano de 2025.

A pesquisa utiliza dados disponibilizados pela **Agência Nacional do Petróleo, Gás Natural e Biocombustíveis (ANP)**, abrangendo os estados brasileiros e permitindo observar diferenças regionais e variações nos preços ao longo do ano.

## Objetivos

- Analisar os preços médios da gasolina e do etanol no Brasil.
- Comparar os preços entre os dois semestres de 2025.
- Identificar os estados com os combustíveis mais caros e mais baratos.
- Investigar as maiores altas e quedas nos preços médios estaduais.
- Desenvolver visualizações gráficas para facilitar a interpretação dos resultados.
- Extrair conclusões a partir dos dados analisados.

## Tecnologias e bibliotecas utilizadas

- **Python:** linguagem utilizada no desenvolvimento da análise.
- **Pandas:** leitura, limpeza, organização e manipulação dos dados.
- **NumPy:** operações numéricas e cálculos estatísticos.
- **Matplotlib:** criação de gráficos e visualizações.
- **Seaborn:** elaboração de gráficos para análise exploratória.

## Fonte dos dados

Os dados utilizados foram obtidos no portal de dados abertos da ANP:

[Histórico de preços de combustíveis e de GLP – ANP](https://dados.gov.br/dados/conjuntos-dados/serie-historica-de-precos-de-combustiveis-e-de-glp)

## Etapas do projeto

1. Coleta e importação das bases de dados.
2. Limpeza e preparação dos dados.
3. Análise exploratória e estatística.
4. Comparação dos preços entre os semestres.
5. Análise das diferenças entre os estados.
6. Construção de gráficos e interpretação dos resultados.
7. Elaboração das conclusões da pesquisa.

## Resultados

A análise permite observar a distribuição dos preços da gasolina e do etanol entre os estados brasileiros, identificar diferenças regionais e comparar as variações dos preços médios entre o primeiro e o segundo semestre de 2025.
